# Public extraction record

Release scope: framework concepts and executable generic code only.

Included by explicit allowlist: documentation, source code, synthetic examples,
tests, empty record templates, agent instructions and publication checks.
Excluded: real conversation exports, personal archives and databases, title
history from real archives, private configurations, device/account settings,
browser profiles, cookies, keys, logs, authentication bundles, backups, and all
private Git history/LFS objects of the personal Recap system.

No claim is made that a real archive, account export or title workflow was
validated by this release. Runtime test results concern only the generic code and
synthetic fixtures. See README for implemented versus specified behavior and
known integration limits.

The manifest binds this release's file bytes. It excludes itself to avoid a recursive
hash dependency. A source hash establishes identity; it does not establish consent,
authorship or redistribution rights for any archived conversation.
